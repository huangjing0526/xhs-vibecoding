# 小红书内容生产工作台 UI 设计方案

版本：v0.1  
日期：2026-06-09  
关联 PRD：`docs/xhs-product-ui-refactor-prd.md`  
设计方向：苹果极简工作台

## 1. 设计定位

这次 UI 不做营销首页，不做视觉炫技，而是把产品设计成一个高频使用的内容生产工作台。

核心感受：

- 像 Apple Notes + Finder + Final Cut 的轻量生产台。
- 信息安静、操作明确、层级清楚。
- 用户始终知道当前选中的「博主道库、素材、选题、草稿、图片、视频方案」是什么。

一句话设计目标：

> 用低噪声界面承载复杂内容生产流程，让用户像整理文件一样推进小红书内容资产。

## 2. 设计原则

### 2.1 少即是多，但不牺牲效率

- 首页直接进入工作台。
- 不放大 hero，不做宣传文案区。
- 每屏只突出当前模块的 1 个主动作。
- 高级信息收进右侧上下文，不堆在列表里。

### 2.2 用「内容包」串起全流程

所有模块都围绕同一个内容包流转：

```text
博主道库 + 素材 -> 选题 -> 改写 -> 图片 -> 视频 -> 复盘
```

UI 上右侧始终展示当前内容包，让用户不用回忆上一页选了什么。

### 2.3 苹果极简，不是纯白空洞

- 背景使用浅灰，而不是纯白。
- 面板使用白色或半透明白。
- 边框很轻，靠间距、阴影、字重建立层级。
- 小红书红只用于主动作和关键质量结果。

## 3. 全局布局

### 3.1 桌面端结构

推荐三栏布局：

```text
┌────────────────────────────────────────────────────────────────────┐
│ Top Bar: Logo / 当前空间 / 同步状态 / 全局动作                      │
├──────────────┬──────────────────────────────────────┬──────────────┤
│ Left Nav     │ Main Workspace                       │ Context      │
│ 7 模块       │ 当前模块的列表、编辑、预览、生成区     │ 当前内容包    │
│              │                                      │ 下一步动作    │
└──────────────┴──────────────────────────────────────┴──────────────┘
```

尺寸建议：

| 区域 | 宽度 |
|---|---|
| 左侧导航 | 216px |
| 中间工作区 | 自适应，最小 720px |
| 右侧上下文 | 320px |
| 页面最大宽度 | 不限制满屏，但中间内容设置舒适最大宽 |

### 3.2 移动端结构

```text
┌──────────────────────────────┐
│ Top Bar                      │
├──────────────────────────────┤
│ 横向模块切换                 │
├──────────────────────────────┤
│ Main Workspace               │
├──────────────────────────────┤
│ Sticky Primary Action        │
└──────────────────────────────┘
```

右侧上下文在移动端变成底部抽屉。

## 4. 导航设计

### 4.1 一级模块

左侧导航保留 7 个模块：

| 顺序 | 模块 | 图标建议 | 主动作 |
|---|---|---|---|
| 01 | 博主研究 | UserSearch | 蒸馏博主 |
| 02 | 内容资产 | Database | 写入素材 |
| 03 | 选题生成 | Lightbulb | 生成选题 |
| 04 | 爆款改写 | PenLine | 改写内容 |
| 05 | 图片生成 | Image | 生成图片 |
| 06 | 视频生成 | Clapperboard | 生成视频方案 |
| 07 | 数据复盘 | ChartNoAxesColumn | 生成复盘 |

当前项目还没有图标库时，第一阶段可以先用文字和序号，后续接入 `lucide-react`。

### 4.2 导航样式

非选中：

- 白色或透明背景。
- 字色 `#6E6E73`。
- 数字使用浅灰。

选中：

- 背景 `#FFFFFF`。
- 轻阴影。
- 左侧 3px 小红书红指示条。
- 标题字色 `#1D1D1F`。

避免当前厚黑边框和大面积深色选中态。

## 5. 首页工作台

### 5.1 顶部栏

内容：

- 左侧：产品名 `VibeNote Studio`。
- 中间：当前模块名 + 当前模式 `Demo / Connected`。
- 右侧：同步飞书、API 状态、设置。

样式：

- 高度 64px。
- 背景 `rgba(245,245,247,0.82)`。
- `backdrop-blur`。
- 底部 1px 浅边框。

### 5.2 顶部模块标题区

每个模块进入后，中间工作区顶部展示：

```text
模块标题
一句短描述
主按钮 / 次按钮
```

示例：

```text
博主研究
采集样本，蒸馏可复用的爆款判断路径。
[新增样本] [蒸馏博主]
```

不使用大字号 hero，标题控制在 24-28px。

## 6. 右侧上下文设计

右侧上下文是本次重构的关键组件。

### 6.1 内容结构

```text
当前内容包
├─ 博主道库
├─ 本轮素材
├─ 当前选题
├─ 当前草稿 / 改写版本
├─ 图片状态
├─ 视频状态
└─ 下一步动作
```

### 6.2 视觉结构

- 右侧栏背景 `#FBFBFD`。
- 每个信息块用轻分隔线，不用重卡片堆叠。
- 主动作固定在底部。
- 信息不足时显示空态，例如「尚未选择博主道库」。

### 6.3 下一步策略

下一步按钮根据当前模块变化：

| 当前模块 | 下一步 |
|---|---|
| 博主研究 | 选择素材 |
| 内容资产 | 生成选题 |
| 选题生成 | 改写内容 |
| 爆款改写 | 生成图片 |
| 图片生成 | 生成视频方案 |
| 视频生成 | 标记发布 / 去复盘 |
| 数据复盘 | 回到选题 |

### 6.4 完整页面画布

完整页面画布用于指导第一阶段 UI 落地。默认桌面画布按 `1440 x 900` 设计，适配宽屏时中间工作区自然拉伸，左右栏保持稳定宽度。

## 8. 视觉规范

### 8.1 色彩

```text
Page Background: #F5F5F7
Surface:         #FFFFFF
Surface Soft:    #FBFBFD
Text Primary:    #1D1D1F
Text Secondary:  #6E6E73
Text Tertiary:   #A1A1A6

XHS Red:         #FF2442
XHS Red Soft:    #FFF1F3
Success:         #0A7F64
Warning:         #B7791F
Info:            #2563EB
```

使用规则：

- 80% 灰白黑。
- 10% 小红书红。
- 10% 功能色。
- 不使用大面积渐变。

### 8.2 字体

使用 Apple 系统字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "Helvetica Neue", sans-serif;
```

字号建议：

| 用途 | 字号 | 字重 |
|---|---:|---:|
| 页面标题 | 24-28px | 700 |
| 模块标题 | 18-20px | 700 |
| 列表标题 | 14-15px | 600 |
| 正文 | 14px | 400-500 |
| 辅助信息 | 12px | 500 |
| 数字指标 | 20-28px | 700 |

不使用负字距，不随视口缩放字号。

### 8.3 圆角与阴影

圆角：

- 大面板：8px。
- 按钮：8px。
- 标签：6px。
- 输入框：8px。

阴影：

```css
box-shadow: 0 1px 2px rgba(0,0,0,0.04), 0 12px 32px rgba(0,0,0,0.06);
```

只给浮层、当前选中面板、右侧上下文使用轻阴影。

### 8.4 间距

基础间距：4px。

常用：

- 页面边距：24px。
- 模块间距：16px。
- 面板内边距：16px。
- 列表行内边距：12px 16px。
- 表单组间距：12px。

## 10. 交互状态

### 10.1 空态

空态只回答三件事：

- 当前缺什么。
- 为什么需要它。
- 下一步点哪个按钮。

示例：

```text
还没有可用道库
先录入目标博主样本，系统会提炼可迁移的选题和表达规律。
[新增样本]
```

### 10.2 加载态

- 模块局部 skeleton。
- 主按钮显示进行中。
- 不阻塞整个页面，除非首次启动。

### 10.3 错误态

- Toast 使用中文友好文案。
- 面板内保留可重试按钮。
- 不静默吞错。

### 10.4 Demo / Connected

顶部状态显示：

- Demo：浅灰标签。
- Connected：绿色小点 + 飞书已连接。

## 12. 第一阶段落地范围

第一阶段 UI 改造建议只做这些：

- 重构 AppShell：顶部栏、左侧导航、右侧上下文。
- 把当前 5 步导航改成 7 个模块。
- 新增三个前端页壳：博主研究、爆款改写、视频生成。
- 保留现有素材、选题、草稿、图片、复盘业务逻辑。
- 全局视觉从厚边框风格切到苹果极简风。

暂不做：

- 新后端数据表。
- 自动采集。
- 真实视频生成。
- 大规模组件库引入。

## 13. 设计验收清单

- 首页第一屏就是可操作工作台。
- 用户能一眼找到 7 个模块。
- 当前内容包始终可见或可打开。
- 每个模块只有一个最突出的主动作。
- 厚黑边框、大面积强色块被移除。
- 页面主色不是单一红色或单一灰色。
- 移动端不出现文字挤压和按钮溢出。
- 空态、加载、错误、Demo、Connected 都有明确状态。
