# 小红书内容生产工作台产品与 UI 重构 PRD

版本：v0.3 重构方案版  
日期：2026-06-09  
项目：`xhs-vibecoding`  
目标：把现有「小红书内容闭环工作台」升级为「博主研究 + 内容资产 + 图文视频生产 + 数据复盘」的一体化工作台。

## 1. 背景

当前系统已经具备素材入库、选题生成、草稿生成、封面图、内容配图和数据复盘能力。现有流程更像单账号的内容生产闭环，核心链路是：

```text
素材库 -> 选题池 -> 草稿库 -> 图片生成 -> 数据复盘
```

新的产品方向需要增加「博主数据采集」和「博主蒸馏」，把原来的 `distill-blogger`/道库能力从隐藏评分规则升级为显性的产品模块。同时，内容生产需要覆盖图文和视频两种形态，并支持爆款内容改写。

## 2. 产品目标

### 2.1 业务目标

- 建立可复用的博主道库，支撑选题、改写、图片和视频生成。
- 把素材沉淀、选题生成、爆款改写、图片生成、视频生成串成稳定工作流。
- 降低从外部爆款样本到自有内容产出的操作成本。
- 保留现有飞书内容闭环，避免重做已有的数据资产。

### 2.2 体验目标

- 用户进入后能明确知道当前在做「研究」「沉淀」「创作」「生产」「复盘」中的哪一步。
- 每个模块只暴露当前步骤最关键的动作，减少现有界面的密集感。
- UI 风格转向苹果极简：浅色、通透、低噪声、强层级、少装饰。
- 工作台优先服务重复操作，不做营销式首页。

### 2.3 内容质量目标

- 生成内容必须绑定真实素材或明确的博主道库依据。
- 爆款改写必须「借道不借皮」，不能直接复制博主文案、标题或人设。
- 图片和视频生成必须和选题、草稿、博主风格保持一致。
- 不新增未经确认的硬性业务限制。

## 3. 用户与场景

### 3.1 目标用户

- 小红书内容创作者。
- 独立开发者、产品经理、AI Coding 实践者。
- 希望系统化拆解爆款内容并生成自有内容的人。

### 3.2 核心场景

- 采集目标博主内容，沉淀可复用的爆款判断标准。
- 从日报、问题记录、术语库中沉淀素材。
- 根据素材和道库生成选题。
- 将普通草稿改写成更像小红书爆款的表达。
- 生成封面图、内容配图。
- 生成视频脚本、分镜和视频生成提示词。
- 发布后回填数据，复盘下一轮内容方向。

## 4. 产品信息架构

重构后主导航建议分为 7 个一级模块：

| 模块 | 子能力 | 现有承接 |
|---|---|---|
| 博主研究 | 博主数据采集、博主蒸馏、道库管理 | `lib/daoku.ts` 可升级 |
| 内容资产 | 素材沉淀、术语库、素材选择 | 当前素材页、飞书素材库 |
| 选题生成 | 选题提炼、道库评分、选题筛选 | 当前选题池 |
| 爆款改写 | 标题改写、正文改写、结构改写、质检 | 新增 |
| 图片生成 | 封面图、内容配图 | 当前图片生成 |
| 视频生成 | 口播稿、分镜、字幕、视频 Prompt | 新增 |
| 数据复盘 | 数据回填、复盘结论、下一轮方向 | 当前复盘页 |

导航视觉上保留 7 个入口，其中「内容资产」包含素材和术语，「图片生成」包含封面和正文配图。

## 5. 功能需求

### 5.1 博主研究

#### 5.1.1 博主数据采集

目标：把目标博主的公开内容整理为可分析样本。

输入：

- 博主名称。
- 平台。
- 主页链接或内容链接。
- 手动粘贴的笔记标题、正文、标签、封面描述、互动数据。

输出：

- 博主档案。
- 样本列表。
- 标题结构。
- 内容结构。
- 互动表现。
- 可复用特征。

第一阶段范围：

- 支持手动录入和粘贴样本。
- 不自动抓取小红书后台数据。
- 不承诺直接爬取平台页面。

#### 5.1.2 博主蒸馏

目标：从博主样本中提炼可复用的「道」。

输出字段：

- 核心道：这个博主为什么会爆。
- 选题道：什么题容易命中。
- 标题道：标题常用结构。
- 正文道：开头、转折、资产、结尾方式。
- 视觉道：封面、图片、视频的常见表达。
- 语气道：口吻、词汇、节奏。
- 禁区：不能照搬、不能误用的点。
- 适配建议：如何迁移到当前账号。

规则：

- 只提炼判断路径，不复制具体表达。
- 必须标注适配到当前账号后的变化。

### 5.2 内容资产

目标：承接现有素材沉淀能力。

保留能力：

- 本地 Markdown 扫描。
- 写入飞书素材库。
- 术语库沉淀。
- 素材勾选。
- Demo 模式。

新增体验：

- 素材页增加「本轮目标」区域：图文、视频、改写。
- 素材卡片展示是否已用于选题、草稿、图片、视频。

### 5.3 选题生成

目标：把素材和博主道库合并，生成更接近爆款形态的内容卡片。

输入：

- 已选素材。
- 术语库。
- 目标博主道库。
- 内容形态：图文 / 视频。

输出：

- 选题标题候选。
- 读者痛点。
- 核心观点。
- 真实案例。
- 可收藏资产。
- 推荐内容形态。
- 道库命中说明。
- 爆款潜力分。

保留现有能力：

- 内容卡片生成。
- 道库评分。
- 选题合并。
- 飞书写回。

### 5.4 爆款内容改写

目标：把已有选题或草稿改写为更适合发布的版本。

输入：

- 当前选题或草稿。
- 目标博主道库。
- 改写目标：标题 / 正文 / 结构 / 全文。

输出：

- 改写前后对比。
- 3 个标题版本。
- 1 个正文版本。
- 命中道说明。
- 风险提示。

规则：

- 不直接套用博主原句。
- 不编造素材里没有的数据。
- 不加入未经确认的自动发布、私域引流或夸张收益表达。

### 5.5 图片内容生成

目标：把当前图片生成能力升级为图文生产工作区。

子模式：

- 封面图。
- 正文配图。

输入：

- 选题。
- 草稿。
- 博主视觉道。
- 图片类型：流程图、清单图、对比图、时间线、步骤图。

输出：

- 图片方案。
- 可编辑画布。
- PNG 下载。

保留现有能力：

- 封面模板。
- 内容配图模板。
- 图片下载。

### 5.6 视频内容生成

目标：先生成可执行的视频生产方案，不在第一阶段直接生成成片。

输入：

- 选题或草稿。
- 目标博主道库。
- 视频形态：口播、图文快闪、教程录屏、剧情反差。

输出：

- 视频标题。
- 口播稿。
- 分镜脚本。
- 字幕稿。
- 画面提示词。
- 封面文案。
- 视频生成 Prompt。

第一阶段范围：

- 生成视频脚本和 Prompt。
- 不直接调用视频生成模型。
- 不直接发布到平台。

### 5.7 数据复盘

目标：复用现有复盘能力，并回流到选题和道库。

保留能力：

- 阅读、点赞、收藏、评论、分享回填。
- 复盘结论。
- 下一轮选题方向。

新增能力：

- 标注复盘结论命中的博主道。
- 识别「适合图文」或「适合视频」。
- 反向更新改写建议。

## 6. UI 重构要求

### 6.1 视觉方向

整体风格：苹果极简工作台。

关键词：

- 浅色背景。
- 通透分组。
- 大留白但保持工作台效率。
- 低对比边框。
- 精准高亮。
- 少量小红书红作为主行动色。

避免：

- 厚重黑边框。
- 大面积强色块。
- 过多标签和徽章。
- 营销式 hero。
- 装饰性渐变和无意义背景。

### 6.2 页面布局

建议采用三栏：

```text
左侧导航：模块入口
中间工作区：列表、编辑、生成、预览
右侧上下文：当前博主道库、素材、选题、草稿、下一步
```

移动端：

- 左侧导航折叠为顶部模块切换。
- 右侧上下文改为底部抽屉。
- 主操作按钮固定在底部或顶部操作栏。

### 6.3 组件规则

- 卡片圆角不超过 8px。
- 表格和列表优先使用低边框、浅底色和清晰行高。
- 主按钮使用小红书红或黑色，次按钮使用浅灰。
- 阶段状态用简短文字和数字，不堆叠过多颜色。
- 图标按钮优先使用成熟图标库；当前项目未接入图标库时，第一阶段可先用文字按钮。

## 8. 第一阶段 MVP

第一阶段目标：先完成信息架构和前端工作台重构，复用现有生成链路。

包含：

- 新导航：博主研究、内容资产、选题生成、爆款改写、图片生成、视频生成、数据复盘。
- 博主研究前端工作区：手动录入样本、展示蒸馏结果 Demo。
- 爆款改写前端工作区：基于当前选题/草稿生成改写 Demo 或规则结果。
- 视频生成前端工作区：生成视频脚本、分镜、Prompt 的 Demo 或规则结果。
- 图片生成沿用现有封面和内容配图能力。
- UI 统一改为苹果极简风。

暂不包含：

- 自动抓取小红书数据。
- 真实视频模型生成。
- 新飞书表自动创建。
- 多用户权限。
- 自动发布。

## 9. 后续阶段

### 阶段 2：后端与飞书持久化

- 新增博主表、样本表、蒸馏表、改写表、视频方案表。
- 新增对应 API。
- Connected 模式写回飞书。

### 阶段 3：采集能力

- 支持用户粘贴链接后解析公开页面。
- 支持批量导入 CSV/Markdown 样本。
- 对采集失败提供明确错误提示。

### 阶段 4：视频生成

- 接入视频生成模型或外部工具。
- 支持生成视频素材包。
- 支持下载脚本、字幕和 Prompt。

## 10. 验收标准

- 用户能在首页看到新的产品结构，而不是只看到旧 5 步流程。
- 用户能完成一条链路：选择博主道库 -> 选择素材 -> 生成选题 -> 改写草稿 -> 生成图片 -> 生成视频方案。
- 当前已有素材、选题、草稿、图片、复盘能力不丢失。
- UI 明显从硬边框工作台切换到苹果极简工作台。
- 所有接口响应继续保持 `{ code, data, message }`。
- 错误提示继续使用中文友好文案。
